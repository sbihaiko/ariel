# ADR-0004: Everything written is English

## Status

Accepted.

## Context

ariel has one language for its record. Mixed languages make search and review hard.

## Decision

1. **Everything written in ariel is English**: code, comments, docs, ADRs, commit messages, tickets.
2. Write short, plain sentences. One idea per sentence.
3. The owner can talk in another language. The record stays in English.

## Guard

None yet. This rule is a draft until a named guard test exists.
